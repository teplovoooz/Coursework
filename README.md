# Matrix Project

Реализация класса `Matrix` для работы с матрицами над кольцом вычетов Z_n (по модулю n). 
Предназначен для использования в криптосистеме трёхпроходного блочного матричного шифрования.

## Описание

Класс `Matrix` реализует операции над матрицами с элементами, приведёнными по модулю n:

- **Арифметические операции**: сложение, вычитание, умножение (с использованием `__int128` для предотвращения переполнения)
- **Линейная алгебра**: определитель (для любых размеров, включая составные модули), обратная матрица
- **Конструкторы**: нулевая, единичная, из списка значений, случайная, случайная обратимая
- **Проверка обратимости**: матрица обратима, если gcd(det, n) = 1

## Примеры использования

### Создание матриц
```cpp
// Нулевая матрица 2×2 по модулю 26
Matrix A(2, 2, 26);

// Из списка значений
Matrix B(2, 2, 26, {3, 2, 5, 7});

// Единичная матрица
Matrix E = Matrix::identity(3, 26);

// Случайная матрица
std::mt19937_64 rng(42);
Matrix C = Matrix::random(2, 2, 26, rng);

// Случайная обратимая матрица
Matrix D = Matrix::randomInvertible(2, 26, rng);
```

### Операции
```cpp
Matrix A(2, 2, 26, {7, 4, 11, 14});
Matrix B(2, 2, 26, {3, 2, 5, 7});

// Арифметика
Matrix sum = A + B;
Matrix diff = A - B;
Matrix prod = A * B;

// Линейная алгебра
Matrix AT = A.transpose();
long long det = A.determinant();
bool inv = A.isInvertible();
Matrix A_inv = A.inverse();

// Доступ
std::cout << A(0, 1);       // элемент (0,1)
std::cout << A;              // вывод матрицы
```

### Трёхпроходный протокол
```cpp
// Шифрование: A → B·A → B·A·C
Matrix A(2, 2, 26, {7, 4, 11, 14});
Matrix B(2, 2, 26, {3, 2, 5, 7});
Matrix C(2, 2, 26, {1, 4, 2, 9});

Matrix X1 = B * A;
Matrix X2 = X1 * C;

// Расшифровка
Matrix B_inv = B.inverse();
Matrix C_inv = C.inverse();

Matrix X3 = B_inv * X2;
Matrix recovered = X3 * C_inv;  // = A
```

## Детали реализации

### Определитель
- **2×2, 3×3**: аналитические формулы
- **Общий случай**: метод Гаусса с расширенным алгоритмом Евклида (работает для составных модулей)

### Обратная матрица
- Проверка обратимости: gcd(det, n) = 1
- Вычисление через присоединённую матрицу: A⁻¹ = det⁻¹ · adj(A) mod n
- Обратный элемент: расширенный алгоритм Евклида

### Нормализация
- Все элементы автоматически приведены к [0, n-1]
- Отрицательные значения: x = ((x mod n) + n) mod n

### Переполнение
- Умножение элементов: используется `__int128` для промежуточных результатов
- Суммирование: накопление в `__int128` перед взятием остатка

## Тесты

Тесты покрывают:
1. Умножение матриц (включая отрицательные промежуточные значения)
2. Единичная матрица: A·E = E·A = A
3. Определитель: известные значения, составной модуль
4. Обратная матрица: A·A⁻¹ ≡ E (mod n)
5. Необратимые матрицы: исключение при gcd(det,n) ≠ 1
6. Ассоциативность: B(AC) = (BA)C
7. Трёхпроходный протокол (полный цикл)
8. Прямоугольные матрицы

Запуск:
```bash
cmake --build build --target test
```

## Выбранные решения

1. **Тип элементов**: `long long` (64-bit signed) для универсальности. Выбран `__int128` для промежуточных результатов вместо отдельного модульного сложения.
2. **Метод определителя**: Гаусс + расширенный алгоритм Евклида для поддержки составных модулей (например, n=26).
3. **Исключения**: используются `std::runtime_error` и `std::invalid_argument` для всех ошибок.
4. **Генерация случайных**: `std::mt19937_64` с пользовательским seed.
5. **Комментарии**: на русском языке (краткие), имена функций на английском.
